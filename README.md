# Rudraksh — A digital universe

This project was built with [Lovable](https://lovable.dev).

## Portfolio content

The cinematic interface is implemented with an animated React Three Fiber core, procedural stars and nebula, Lenis scrolling, GSAP motion, and Framer Motion interactions. Reduced-motion preferences disable ongoing animation.

The portfolio content lives in `src/components/portfolio/data.ts`. Rudraksh’s verified education — B.Tech in Artificial Intelligence & Data Science at JECRC University, currently 2nd Year / 3rd Semester — appears in the hero, the Human.config panel, the flight-path timeline, the footer, and the Person schema. Project artwork and technology lists remain explicitly illustrative. Graduation year, email, social profiles, location, résumé, professional history, and credentials are intentionally unset. Add verified details before sharing the portfolio as complete.

Contact currently reports that delivery is unavailable. With a real email configured, it opens a draft in the visitor’s email application; it does not claim to send messages itself.

## Deployment status

This workspace retains its required TanStack Start / React 19 framework and Lovable deployment target. It is not a Next.js application, and direct Vercel deployment, Vercel analytics, and the requested Next.js `start` workflow are not implemented or verified. Use Lovable publishing for the configured deployment. A different hosting target requires a separate supported configuration.

Page metadata, OpenGraph, Twitter cards, and Person schema are present. Existing robots rules permit crawling. Sitemap creation awaits a real public URL; do not use the private preview URL as the canonical domain.
